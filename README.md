# T4-work-coordination 做题记录

## 1. 三个函数分别表示什么

difference表示出现在不同成员中的特有的项目，intersection表示所有成员公有的项目，union表示这个项目列表中所有的不同项目

## 2. 为什么"共同任务"不能只比较前两位成员

只比较前两位的得到的是前两位的共有项目而不是所有人的共同项目

## 3. Set 和数组有什么不同

set可以自动去重而数组会保留重复元素，在本题的union中我利用set去除掉了重复的项目只保留了不同的项目列出了所有项目的清单

## 4. 遇到的问题和解决方法

在intersection中我遇到了如果tasklists 为空是该返回什么的问题，我通过if关键词判断taskLists.length === 0，成立时直接 return []解决了这个问题
